# Mech Prototype

> Initial text-only setup notes, retained as a historical snapshot. The current
> [Overview](overview.html) is the maintained project page.

**Prototype project and living wiki | Started 23 October 2026**

This card brings together the prototype, generated assets, playtest evidence,
and agreed decisions as the game takes shape.

## Confirmed direction

- A roguelike / roguelite game. The exact approach to runs and persistent
  progression is still open.
- Gameplay inspired by the **Armored Core** series. The specific mechanics
  to explore are still open.

These are the only confirmed game-design commitments. This project starts
with its own brief; the game concept, proposed scope, content counts, art
direction, and estimates from Project Playground do not define this game.

## Still to decide

Engine and project starting point; the first playable test; movement, camera,
and combat details; run structure and progression; setting and visual style;
and the scale of the game.

## Working approach

Build and evaluate prototypes before continuing the production research.
Keep proposals distinct from agreements, and record what a playable test
actually shows before using it to revise estimates or commit to production.
Keep future revisions and generated work together on this card.
